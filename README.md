# Worst Superpower

One funny line: the worst superpower imaginable. `main.ts` (Node 22) writes it to `/output/entry.txt`:

> I can turn back time by three seconds, but it takes me four seconds to do it.

The power undoes itself — rewinding three seconds costs four, so every use leaves you one second worse off than doing nothing. Deterministic output, no network, no dependencies.

Run it with:

```sh
node main.ts
```
